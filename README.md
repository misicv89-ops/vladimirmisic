# Studio / Vladimir Misic — Portfolio

Single-file website (`index.html`) — all fonts, scripts and animations are bundled. Works on desktop and mobile.

## Publish on GitHub Pages
1. Create a new repository and upload `index.html`, `robots.txt`, `sitemap.xml` (and this README).
2. Repository → **Settings → Pages** → Source: *Deploy from a branch* → `main` / `root` → Save.
3. The site goes live at `https://<username>.github.io/<repo>/` within a minute.

## Before going live
- Replace `https://example.com/` in `index.html` (canonical, Open Graph), `robots.txt` and `sitemap.xml` with your real domain.
- Contact form sends to **misicv89@gmail.com** via FormSubmit — the first submission triggers an activation email; click the link once.
- Image placeholders (hero, about) are empty — add real images later.
